# Stocker — локальный веб-интерфейс v1

Рутина без Claude Code: положил фото → видишь счётчики → разбираешь «Требует внимания» →
собираешь файлы к загрузке в плоские папки. Паспорт §35ZZZN.

## Запуск

```bat
scripts\start_ui.cmd
```

Открыть в браузере: **http://127.0.0.1:8780/**. Остановить — `Ctrl+C` в окне.

- Работает только на production-каталоге (`STOCKER_DATA_DIR=data/prod` задаёт скрипт);
  с тестовым каталогом не запускается.
- Слушает только `127.0.0.1` — с других компьютеров недоступен.
- Новые фото обрабатываются штатным pipeline (как раньше) — интерфейс показывает
  результат и принимает решения человека; сам файлы не регистрирует.

## Экраны

| Экран | Что делает |
|---|---|
| Панель | счётчики: одобрено и ещё не собрано, требует внимания, заблокировано, отклонено, проблемы с источником; недавние события; кнопка «Собрать к загрузке» (активна только когда «требует внимания» = 0) |
| Требует внимания | по одному объекту: превью до 2000 px, «Открыть 100%», причины человеческим языком (gate, QC, чёрные полосы с рекомендуемой обрезкой), title и ключевые слова — только чтение; «Одобрить», «Отклонить» (причина обязательна), «Пропустить»; при людях в кадре — «Люди в кадре не узнаваемы» (аттестация) |
| Одобрено | сетка превью, статус по площадкам (готов / в партии NNN), «Открыть 100%», «Вернуть на проверку» |
| Заблокировано | причина и что делать; для «Узнаваемые люди без релиза» — подтверждение «люди не узнаваемы» |
| Отклонено | объект, исходный файл, причина, дата |

После «Одобрить» интерфейс, как и ручной поток, запускает Readiness и Publication — объект
становится одобренным для площадок. Одобрение человеком нельзя «вернуть на проверку»
(эскалация допускается только для автоодобренных) — интерфейс покажет сообщение.

## Собрать к загрузке

1. Для Adobe и Shutterstock: файлы площадки готовятся одобренным объектам без актуального
   экспорта; отказы показываются в отчёте.
2. `export.collect` копирует актуальные, ещё не собранные файлы в
   `data/prod/publish/<platform>/<NNN>_<YYYY-MM-DD>/` + `manifest.csv`
   (asset_id, filename, title / description, words, sha256). Повторный сбор — следующая
   партия только из новых файлов.

Загрузку на площадки интерфейс не выполняет.

## Безопасность

- Все действия — операции сервисного слоя от имени `human` (те же, что CLI / MCP).
- Каждый POST проверяет токен сессии сервера (новый при каждом запуске).
- Фото отдаются только по номеру объекта; путь из адреса не принимается.
