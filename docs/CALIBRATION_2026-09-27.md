## 4. Выводы калибровки

1. **Enhancement — главный источник ложных сигналов** (26 % отобранных кадров
   помечены «улучшить», подтверждённых случаев нет). Нужна перекалибровка
   (аудит P3): пороги блочности для JPEG Pixel, резкость по резким участкам
   кадра (боке ≠ размытие), фактура ≠ артефакты.
2. **Creative Review на профиле `industrial_stock` отражает отбор на 83 %**;
   несогласия объяснимы: (а) нетематические кадры → нужны другие профили;
   (б) ориентир для текстур → ослабить в `industrial_stock` v2.
3. QC, Vision, Metadata, gate, Readiness — согласуются с отбором; нагрузка на
   человека — 10 % (бренды на оборудовании и шильдики).
4. Отбор пользователя шире одной тематики — подтверждает принцип §3A.9.
