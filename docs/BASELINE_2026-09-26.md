## 5. Pipeline и решения

- Pipeline: ingest (SHA256, дубликаты) → QC → Vision → Metadata AI → Python
  validation / grounding → review gate → `auto_approved` | `human_review` |
  `draft` (partial).
- Review gate `gate-v1.1`: к человеку — бренды/логотипы (Vision), юрлица и
  юридический текст на изображении, юридические утверждения в metadata,
  неподтверждённые конкретные утверждения, узнаваемые люди, editorial risk,
  AI-generated, ручная эскалация. Технический и описательный текст, частичное
  присутствие людей — не блокируют.
